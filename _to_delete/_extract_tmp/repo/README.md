# Python for Transport & Civil Engineering

Five weeks. By the end you will be able to take a messy transport dataset, clean it,
analyse it, and produce a figure that makes an argument — and get yourself unstuck
when it doesn't work.

## Start here

**Before week 1**, do this — it takes about an hour and it is not optional.

1. Follow the setup guide for your machine:
   - Windows → [`setup/windows.md`](setup/windows.md)
   - macOS → [`setup/macos.md`](setup/macos.md)
   - Work laptop with no admin rights → [`setup/locked-down-laptop.md`](setup/locked-down-laptop.md)
   - Nothing working → [`setup/colab-fallback.md`](setup/colab-fallback.md)

2. Open a terminal in this folder and run:

   ```
   python check_setup.py
   ```

3. Copy everything it prints and submit it.

**If it fails, submit the error text instead.** That is just as useful. Do not spend
your evening fighting an installer — we will fix it before the session.

## Ground rules

- **A figure with an unlabelled axis is not finished.**
- **Working code you can't explain is not finished either.** From week 3 onwards you
  will be asked how you know your answer is right.
- Getting stuck is the job, not a failure at it. Bring the traceback.
