# Setup — work laptop with no admin rights

> **STUB.** To be written.

For students on managed or corporate machines where installers are blocked.

Options in order of preference:
1. Check whether the institution's software centre already offers Python and VS Code.
2. User-scope install (`--user`) where the installer permits it.
3. Portable/WinPython.
4. Fall back to Colab — see `colab-fallback.md`. **This is not a lesser option and
   should not be presented as one.**

Any student on this path should be identified during pre-work triage, not on the
morning of week 1.
